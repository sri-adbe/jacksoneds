# table-product

Custom **table** block. Purpose: data table comparing products or listing forms, with links in cells and sortable columns.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per table row; the first row is the header. Cells may hold links and line breaks. Click a header to sort by that column. The extra no-header option (not in the catalog) skips the header row.
