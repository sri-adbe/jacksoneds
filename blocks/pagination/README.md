# pagination

Custom **custom** block. Purpose: page-number navigation under an article listing.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: page links (1, 2, ...) and optional first/previous/next/last links (text or «, ‹, ›, »), in one cell as a list or paragraphs, or one per row. An unlinked number is the current page.

## Supported variations

No variations.
