# cards-feature

Custom **cards** block. Purpose: wrapping grid of icon-led feature items, each with a heading, text and optional list or button.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per item: icon or image | heading + text + optional list + optional CTA link. The icon may instead be the first paragraph of the body cell. Text-only rows (process steps) are fine.

## Supported variations

| Variation | Option class |
| --- | --- |
| Alt | `alt` |
| Icon Left | `icon-left` |
| Dark Light | `dark-light` |
