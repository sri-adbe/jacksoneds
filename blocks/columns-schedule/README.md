# columns-schedule

Custom **columns** block. Purpose: intro text beside a table of dates (grant cycle deadlines).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: heading + text | optional caption. Rows 2+: table rows, the first being the header row (its first cell may be empty); first cell of each later row is the row label.

## Supported variations

No variations.
