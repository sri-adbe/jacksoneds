# list-filter

Custom **custom** block. Purpose: checkbox filter chips (or a year selector) that filter the listing below them.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional heading (filter label), then filter values as a list, paragraphs or one per row. A value starting with All clears the filter. 8+ values, or all years, render as a select.

## Supported variations

| Variation | Option class |
| --- | --- |
| Light Blue Orange Magenta | `light-blue-orange-magenta` |
| Alt | `alt` |
