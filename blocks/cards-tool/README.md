# cards-tool

Custom **cards** block. Purpose: grid of tool cards (image, titled box, CTA) and, with the partner options, a directory of partner tiles with tag labels or logos.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per card: optional image or logo | optional tag paragraph + title + text + CTA link. Partner tiles: tag paragraph (e.g. Direct Integration), partner name or logo, integration link.

## Supported variations

| Variation | Option class |
| --- | --- |
| Partner | `partner` |
| Partner Logo | `partner-logo` |
| Grey Cyan Orange | `grey-cyan-orange` |
| Grey Blue Cyan Orange | `grey-blue-cyan-orange` |
