# tabs-product

Custom **tabs** block. Purpose: product page shell: product title, a tab strip (Overview, Product highlights, Product comparison) and the product hero beneath it.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional first row: product title heading (single cell). Then one row per tab: label (may include an icon; a link with no panel makes a link tab to a sub-page) | panel content. A panel holding one picture plus heading and text renders as a photo with an inset text box. A panel holding only a bare page URL loads that page as a fragment.

## Supported variations

No variations.
