# columns-feature

Custom **columns** block. Purpose: text and selling message beside a photo or video; the site's most common split layout.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row: heading + text + optional list + CTA links | image or video link, in either order. An icon paragraph followed by copy in the text column becomes an icon callout. More rows stack more splits.

## Supported variations

| Variation | Option class |
| --- | --- |
| Image Left | `image-left` |
| Alt | `alt` |
