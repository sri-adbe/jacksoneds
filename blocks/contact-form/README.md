# contact-form

Custom **custom** block. Purpose: intro copy beside a lead-capture form (consultant contact, email form), optionally with a contact-details column; submission is not wired to a backend.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: content rows (heading, intro text, links) then field rows `label | type | options/help` (types: text, email, tel, number, date, textarea, select, radio, checkbox, checkboxes, submit, reset). Content rows after the last field become a contact-details column (phone numbers, addresses). Content rows between fields stay inside the form.
