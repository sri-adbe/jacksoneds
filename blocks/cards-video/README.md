# cards-video

Custom **cards** block. Purpose: side-by-side video items, each with a player, optional icon, heading, description and button.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per video: video link (YouTube, Vimeo, Brightcove, Vidyard, Wistia or .mp4; an optional poster picture right before it) | optional icon + heading + text + CTA link.

No variations.
