# location-tiles

Custom **custom** block. Purpose: horizontal row of office photo tiles; the open tile widens to show its description and a jobs link.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per location: photo | location name | description + link. The name may instead be the first paragraph of the details cell. The first tile starts open.
