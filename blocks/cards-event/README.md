# cards-event

Custom **cards** block. Purpose: list of dated webinars or events, each with a title, description and register link.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per event: date and time | title heading + description | register link. Missing cells are fine.
