# embed-video

Custom **embed** block. Purpose: standalone embedded video player (Brightcove player or playlist on the source).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: the video URL as a link (YouTube, Vimeo, Brightcove, Vidyard, Wistia or .mp4); optional poster picture; optional caption text.

No variations.
