# forms-finder

Custom **custom** block. Purpose: keyword search and dropdown filters over the forms library, with a list of forms.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: field rows: `Search for keyword or form number | search`, `Category | select | options`, `Search | submit`, `Clear all | reset`. Content rows: the forms list as a list of links or a table (one form per item or row).
