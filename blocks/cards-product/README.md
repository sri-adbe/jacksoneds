# cards-product

Custom **cards** block. Purpose: grid of product or category cards, each linking to a detail page or product documents.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per card: optional image | optional eyebrow (product type) paragraph + heading + description + one or more CTA links. For Link Columns, put two link lists in the body (or two body cells) to show them side by side.
