# retirement-calculator

Custom **custom** block. Purpose: static rendering of the interactive retirement expense calculator: heading, step indicator, inputs and buttons, or just the launch button on calculator landing pages.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: content rows (heading, intro, results header, launch link) and an optional ordered list for the step indicator (bold item = current step), plus field rows `label | type | options/help` for the inputs.

## Supported variations

| Variation | Option class |
| --- | --- |
| Red | `red` |
| Red 2 | `red-2` |
| Red 3 | `red-3` |
