# accordion-manager

Custom **accordion** block. Purpose: grid of investment-manager logo tiles; each tile expands to reveal the manager's details.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile: logo image | manager name | details (rich text). Logo and name may share the first cell. A row without a details cell renders as a static tile; the Red option uses that for a row of category pills.
