# hero-banner

Custom **hero** block. Purpose: background photo banner with an inset box holding heading, text and a CTA.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: background picture (own row or cell) + content cell: heading, text, optional CTA links. Order does not matter; image or CTA may be missing.

## Supported variations

| Variation | Option class |
| --- | --- |
| Orange | `orange` |
| Blue | `blue` |
| Cyan | `cyan` |
| Grey | `grey` |
