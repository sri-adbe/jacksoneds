# tabs-section

Custom **tabs** block. Purpose: tab bar switching panels of content (state-specific product panels, resources, FAQs, research topics).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab: label (text, optional icon) | panel content (any rich content). A panel holding only a bare page URL loads that page as a fragment so it can contain other blocks; links under /fragments/ are loaded by the page's auto-blocking. A label that is a link with an empty panel is a link tab.
