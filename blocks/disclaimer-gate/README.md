# disclaimer-gate

Custom **custom** block. Purpose: considerations copy beside a photo with an acknowledgement checkbox that enables the tool start button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: image | heading + text + list + start link. Optional row: `I understand | checkbox` (added automatically when missing). The last link-only paragraph is the gated start link.
