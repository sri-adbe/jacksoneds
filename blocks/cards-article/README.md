# cards-article

Custom **cards** block. Purpose: grid of article teaser cards (photo, topic tag, date, title, summary, read time) linking to article pages.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per article: image | body. Body order: tag paragraph, date paragraph, title heading (linked to the article), summary, optional read time ("6 min"). The title link, or the first link, covers the whole card.
